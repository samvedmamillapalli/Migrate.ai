# --- CockroachDB Managed MCP Server client dependencies ---

# Without these, ExecuteMigrationFunction logs "mcp package not installed;
# skipping MCP investigation" and app/shadow/blast_radius_investigator.py never
# runs in production. See docs/HACKATHON_INTEGRATION_AUDIT.md §2.
#
# `mcp` itself is deliberately NOT listed here. Its wheel metadata declares
# `pywin32>=311; sys_platform == "win32"`, and pip's cross-platform
# `--platform manylinux2014_x86_64` install evaluates environment markers
# against the PACKAGING machine's interpreter, not the target platform (a
# documented pip limitation, not a version-specific bug). Because this project
# packages Lambdas from Windows by design (see package_lambda_for_sam.py's
# docstring), listing `mcp` here makes every `sam build` fail with:
#   ERROR: Could not find a version that satisfies the requirement pywin32>=311
# ...since pywin32 has no manylinux wheel. Verified by direct reproduction.
#
# Instead, package_lambda_for_sam.py installs `mcp` separately with --no-deps
# (pywin32 is never needed on Lambda's Linux runtime), and its real runtime
# dependencies are listed below so they resolve normally with full conflict
# checking against the rest of this file.
#
# This list is mcp==2.0.0's Requires-Dist minus: pywin32 (win32-only) and the
# `cli`/`rich` extras (not installed). Re-derive if mcp is upgraded:

#   python -c "import zipfile,glob;z=zipfile.ZipFile(glob.glob('/tmp/m/mcp-*.whl')[0]);\
#   print(z.read([n for n in z.namelist() if n.endswith('METADATA')][0]).decode())" | grep Requires-Dist
